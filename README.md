# ВКР БГПУ — расписание 1С и интеграция с кампусом

Проектирование и разработка механизма интеграции подсистемы формирования расписания «1С:Университет ПРОФ» с кампусной системой БГПУ.

## Статус на 25 ноября 2026 года

В тестовой базе успешно выполнены 33 сценария валидатора. Подготовлены контрольное расписание 4МО, спецификация чтения и исходник диагностики метаданных. В HTML-выгрузке выявлены расхождения, которые еще сверяются. Рабочий API расписания и собранная поставка расширения не завершены. Новый диагностический код и пример HTTP-ответа не проверены; отладка зависит от корректировки публикации на сервере БГПУ.

## Проверки репозитория

```powershell
python tools/check_repository.py
```

Эта команда проверяет структуру спецификаций и примеры дат. Она **не компилирует и не исполняет BSL**. Порядок проверки средствами платформы приведен в `src/README.md`.
