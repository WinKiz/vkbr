# ВКР БГПУ — расписание 1С и интеграция с кампусом

Проектирование и разработка механизма интеграции подсистемы формирования расписания «1С:Университет ПРОФ» с кампусной системой БГПУ.

## Статус на 11 ноября 2026 года

Репозиторий начат с нуля. Согласованный объем восстановлен из ТЗ, материалов ВКР и уточнений заказчика. Подготовлены спецификации, план и первые исходники BSL. **Собранного расширения CFE, работающего HTTP-сервиса и подтвержденного расписания пока нет.** Проверки в реальной конфигурации отмечаются отдельно от проверок документов и исходного кода.

## Как работаем по SDD

SDD здесь означает Spec-Driven Development: спецификация → технический план → задачи → реализация → проверка критериев приемки. Структура использует подход GitHub Spec Kit, но CLI и slash-команды Spec Kit в этот репозиторий не установлены. Для работы достаточно файлов и Git.

1. Прочитать [правила проекта](.specify/memory/constitution.md) и [контекст](docs/project-context.md).
2. Для функции заполнить `spec.md`: поведение, ограничения, примеры и критерии приемки.
3. Описать реализацию в `plan.md`, разбить ее на проверяемые задачи в `tasks.md`.
4. Реализовать небольшой шаг; сохранить результат проверки. Не считать код проверенным только потому, что он написан.
5. При изменении решения обновить спецификацию и [журнал решений](docs/decisions.md).

```powershell

```

Эта команда проверяет структуру спецификаций и примеры дат. Она **не компилирует и не исполняет BSL**. Порядок проверки средствами платформы приведен в `src/README.md`.
