# ВКР БГПУ — расписание 1С и интеграция с кампусом

Проектирование и разработка механизма интеграции подсистемы формирования расписания «1С:Университет ПРОФ» с кампусной системой БГПУ.

## Статус на 11 ноября 2026 года

Репозиторий начат с нуля. Согласованный объем восстановлен из ТЗ, материалов ВКР и уточнений заказчика. Подготовлены спецификации, план и первые исходники BSL. **Собранного расширения CFE, работающего HTTP-сервиса и подтвержденного расписания пока нет.** Проверки в реальной конфигурации отмечаются отдельно от проверок документов и исходного кода.

Рабочая платформа: **8.3.27.2342**; конфигурация: **Университет ПРОФ 2.3.2.28**. Основной язык продукта — встроенный язык 1С. Python применяется только для вспомогательных проверок репозитория.

## Проверки репозитория

```powershell
python tools/check_repository.py
```

Эта команда проверяет структуру спецификаций и примеры дат. Она **не компилирует и не исполняет BSL**. Порядок проверки средствами платформы приведен в `src/README.md`.
